# Procedural and synthesized sound effect techniques (Web Audio / sample-level recipes)

## Principles
- Pitch comes from harmonic ratios, material comes from inharmonic ratios. Use real mode tables (glass 1 : 2.32 : 4.25 : 6.63 : 9.38, aluminum bar 1 : 2.756 : 5.423 : 8.988, wood plate 1 : 1.47 : 2.09 : 2.56, bowl 1 : 2.778 : 5.181 : 8.163) and only vary f0, never the ratios, so a material keeps its identity across plays. [1, 3, 6]
- Higher modes die faster. Give mode k a T60 roughly proportional to f^-0.6 to f^-1. STK pole radii imply it: marimba 0.9996/0.9994/0.9994/0.999 is T60 0.39/0.26/0.26/0.16 s at 44.1 kHz (T60 = 6.908 / (-ln r) / sr). [3]
- Real bells and bowls ring in doublets 0.1 to 1 percent apart; the resulting 2-30 Hz beating is the shimmer. The handbell table has pairs 1312.0/1314.5 Hz (2.5 Hz beat) and 4966.6/4993.7 Hz (27 Hz beat). Add a +0.2 to +0.5 percent twin to important modes. [1, 11]
- Convert a decay time to a native filter: a BiquadFilter bandpass fed an impulse is a damped mode with Q = pi * f * T60 / 6.908 (2 kHz at 0.5 s is Q 455). A bank of 4-8 of these is modal synthesis with no sample loops. (derived)
- FM bell rule: non-integer ratio + index that falls with the amplitude + long exponential decay. Chowning's bell is 1 : 1.4 with index max 10; ratio 1/sqrt(2) with index under 2 gives a soft mallet; index envelope is the brightness knob. [9, 10]
- Web Audio traps: a DelayNode inside a feedback cycle is clamped to at least 128 samples (2.9 ms at 44.1 kHz), so combs, Karplus-Strong and tube resonators above about 340 Hz must be sample-level or feed-forward only; WaveShaper input clamps at +-1, so fold depth is set by the input gain; set convolver.normalize before .buffer and build IRs at the context sample rate. [18, 19]
- Layer every impact as transient (0 to 5 ms click) + body (80-400 ms modal) + sub (55-90 Hz) + tail (reverb send) + a -24 dB sweetener; moving the transient 2-6 ms ahead of the body makes the sound feel larger. [23]
- Sine bass below 80 Hz vanishes on laptop speakers; add 25-40 percent parallel tanh saturation so the 2nd and 3rd harmonics (120-180 Hz for a 60 Hz sub) carry the weight. [22, derived]
- Granular rules: 20-45 ms Hann grains for soft clouds, 5-10 ms for buzzy digital grit, below 5 ms pitch is lost, density is what turns clicks into a continuous cloud. [21]
- Many random collisions through 2-5 fixed resonances (PhISEM) sound physical and cost almost nothing: shared system energy that decays slowly, per-event noise that decays in a few samples. [4, 29]
- Offline rendering means hero-event times are known, so sidechain ducking is plain gain automation on the music bus with anticipation, not a compressor (DynamicsCompressorNode has no sidechain input). Hero sounds should be rare and consistent. [27, derived]
- Seed everything per play but vary little: f0 +-3 to 6 percent, gain +-2 dB, decay +-15 percent, mode detune +-0.3 percent. Keep ratio tables and envelope shapes fixed.
- Honesty note: ratio tables, radii and parameter names are copied from the cited sources; envelope times, levels and ranges marked "start" are my starting values to tune by ear; items marked (derived) come from standard acoustics or DSP, not a fetched page.

## Shortlist for 3dlight
1. lpgPluck - a warm, round pluck whose brightness dies with loudness; replaces felt piano with a distinct, soft voice that suits matte spheres.
2. ceramicTap - porcelain tick from the STK mug table; a clean "capsule lands in tray" cue that is not the glass clink.
3. membraneTap - soft skin boop with true membrane modes; the cell and sphere touch sound.
4. bounceSettle - restitution-based soft bounces with a tiny roll; physically plausible landing of matte 3D objects.
5. subDrop - saturated sub boom for beat-one anchors; carries on laptop speakers and replaces the soft kick as the main impact.
6. tonalSwoosh - noise whoosh turned into a pitched, in-key sweep; a transition with identity instead of plain filtered noise.
7. grainCloud - tonal grain mist for dissolves; matches the smooth dissolve visuals and is calm.
8. shepardBed - endless glide bed that repeats exactly every 4.5 s beat, so the 45 s loop has no audible seam.
9. rissetBell - deep beating bell for the end card or title; a hero tone far from glock and chime.
10. tuningForkPing - clinical, near-sine lab ping; credible biotech tone for measurements and number reveals.

Also worth building as shared infrastructure (not counted above): irPresets (one consistent space), duckBus (hero sounds read cleanly), transientShape k = -0.4 (matte character across all sounds).
