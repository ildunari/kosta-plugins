# v0.16.3 state (2026-09-23)

Voice-over build 5: the narration tool (`toolkit/voice.mjs`, added in the release before) speaks with three more
providers. Nothing in the engine or the film workflow changed. (0.16.2 was left for the sound build that claimed it.)

## What changed

- **Grok, ElevenLabs and Inworld.** `--provider xai` (Grok's `/v1/tts`, voice orion), `--provider elevenlabs`
  (`eleven_v3`, voice Darian; a name on the account, a voice ID, or one of the six narrators that replace the
  retiring default voices) and `--provider inworld` (`inworld-tts-2`, voice Dennis). Keys come from
  `XAI_API_KEY`, `ELEVENLABS_API_KEY` and `INWORLD_API_KEY`, or `~/.config/doodle-art-animation/keys.env`. A
  refused or missing key stops the run and names the variable to set.
- **Word timing from the provider.** All three report when each word or character is spoken. Those times are
  lined up with the script's words by matching their letters, so respellings and tags the provider echoes don't
  break it, and `vo/voice.json` records `timing: "words"`. A mark such as `{count}` then lands on its word instead
  of being placed by syllable count (about 0.3 s off). Under 60% matched letters, the tool falls back to the
  pauses as before.
- **Tags per provider.** A pause tag becomes `[pause]` / `[long-pause]` for Grok, `...` for `eleven_v3`, and
  `<break time>` for older ElevenLabs models and Inworld. Inworld TTS-2 takes the film's direction as its
  `instruction`; Grok and ElevenLabs have no direction field.
- **OpenAI.** Realtime models, and voices `tts-1` lacks, are refused before a request is sent.
- **`keys --test`** covers the new providers. A provider with no key is reported but does not fail the run.
- **`references/voice-providers.md`** lists the providers, their keys, prices and timing, and how to run a local
  voice on a Mac (Kokoro-FastAPI or mlx-audio).

## How it was checked

- Request and response formats were read from each provider's docs on 2026-09-23.
- `tests/doodle-art-animation/voice_test.mjs` has pretend Grok, ElevenLabs and Inworld servers: request format,
  key headers (and that no key is printed), the missing-key message, word timing and marks, a respelled word, the
  ElevenLabs voice lookup and known IDs, and an Inworld `id:secret` key.

## Known limits

- Only a Gemini key exists in the cloud environment, so no real request has been made to Grok, ElevenLabs or
  Inworld yet. The first real run of each should be a short audition.
- ElevenLabs' docs do not say whether `eleven_v3` returns character times; if it does not, that provider falls back
  to the pause-based timing.
- The upbeat voice picks for the three new providers are guesses to audition, not researched choices.
