# v0.19.0 state (2026-10-10)

The plugin now makes films in more than one style. The original notebook style is **Doodle Draw**; the new
**3DLight** style makes clean, matte 3D motion graphics on a light ground (the look of the Brown expo booth loops).
Both take their sound effects from a new shared **sound library** of 130 synthesized effects and instrument voices.
The plugin keeps its name, `doodle-art-animation`, and its five commands.

## What changed

- **Styles.** Each style is a folder, `skills/doodle-art-animation/styles/<id>/`, with its own `STYLE.md`,
  `references/` and `toolkit/`. The main `SKILL.md` is a router: it picks the style, writes `style: <id>` as the
  first line of `brief.md`, and follows that style's `STYLE.md`. No `style:` line means Doodle Draw, so every film
  made before v0.19 still builds the same way. `styles/README.md` is the registry and says how to add a style.
- **Doodle Draw** is the old toolkit and references, moved into `styles/doodle-draw/` without changes to how films
  draw. The reviewer agents read the `style:` line and, for any other style, that style's "Reviewers" section.
- **The sound library** (`skills/doodle-art-animation/sound-library/`). `sfxlib.js` holds 130 effects in 10 families
  (transition, impact, ui, digital, organic, liquid, material, tonal, texture, rhythm), each with a description, the
  on-screen moments it fits, its options and the styles it suits: 127 suit 3DLight and 52 suit Doodle Draw.
  Everything is computed at render time from a seeded random generator, so repeats vary and a re-render is identical.
  It was built from four research catalogs written by separate research agents (motion and interface sound, biology
  and materials, synthesis techniques, music beds), kept in `research/` with their sources. `catalog.md` is
  generated from the effects' own metadata, and `catalog.mjs --page` writes a listening page (search by moment,
  filter by style and family, three variations of each effect).
- **Each toolkit carries a copy** of `sfxlib.js` (a film folder is a copy of a toolkit). `sync.mjs` keeps the copies
  identical, and both `sync.mjs --check` and `sfxlib_test.mjs` fail on a stale copy.
- **Doodle Draw plays library effects as cue names**, trimmed 10 dB so `g: 1` sits at the level of its own cues. An
  engine sound with the same name keeps the engine's version. Library effects count as varied sounds in `cue_check`.
- **3DLight** (`styles/3dlight/`): matte 3D primitives (`l3d.js`), a beat engine with dissolves and an optional
  seamless loop (`beats.js`), parallel rendering, a smoke test, a starter example and the biocoating booth loop as
  examples. It has no narration and no camera moves.
- **3DLight music beds.** `sound.music: { bed, key, level }` picks one of three beds built note by note from the
  library's instrument voices (`E.voice`): `glassPulse` (the default; pulse minimalism), `slowAir` (ambient, no drums
  or bass line) and `quietEngine` (a quiet synth groove). Each follows a five-chord cycle, two beats per chord, and
  a ten-step build-and-thin shape over the film's beats, so any film length gets a shape and a loop's last beat
  matches its first. The sound before v0.19 (pad, bass, felt keys or glass mallet, soft kick, knock and shaker)
  plays as the `classic` bed when `music` has `chords`.
- **CI** checks the catalog and the toolkit copies, runs the library test and the 3DLight smoke test, with a 30
  minute job limit.

## How it was checked

| Check | Result |
|---|---|
| `sfxlib_test.mjs` (every effect rendered three times: silence, peak -22 to -5 dBFS, same seed identical, other seed different, tail length, metadata) | 130 of 130 pass |
| Doodle Draw smoke test, narration test, regression and effects tests on the new layout | 8/8, 26, 56 and 9 pass |
| 3DLight smoke test (both examples: build, stills, loop seam, effect names) | 2/2 pass |
| Static acceptance check | 151/151 |
| Bed loudness, dry, on the biocoating loop | classic -30.1, glassPulse -30.4, slowAir -30.4, quietEngine -31.1 LUFS |
| Listening page at phone and desktop width | no console errors, no sideways scrolling |

## Known limits

- Nobody in the build loop can listen. Levels and balance were measured (per-effect peaks, per-cue level against the
  music, loudness, spectrograms), but whether a sound is pleasant was judged only from those numbers and the
  research. Expect a few effects to need retuning once someone listens to the page.
- A 3DLight story without a `music` field now gets `glassPulse` in D instead of the old A-minor mallet bed.
- The library's resonator helper (`H.DSP.reson`) does not block very low frequencies. The effects that use it feed
  it noise, which has almost none, and the library test passes all of them, so it was left alone (3DLight's master
  bus also high-passes at 32 Hz; Doodle Draw's does not). A new effect that feeds it a signal with an offset should
  high-pass its own output.
- The captions work in PR #27 (0.18.0, not merged) touches Doodle Draw files that moved in this release; it will
  need its paths updated before it merges.
- The mesophase implant booth loop is not in the repo: its numbers are unpublished. Only the published biocoating
  loop ships as an example.
