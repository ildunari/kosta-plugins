# v0.14 state (2026-09-18)

Branch `doodle-v0.14`. v0.14 rebuilt the workflow after a real Cowork run fired `script-reviewer` and then
`sound-designer` before a script existed, wrote the script afterwards, built on stale reviews, and did every
step one after another. The agreed ledger is W1–W9 in `ACCEPTANCE.md`; v0.13's L1–L17 still apply.

## What changed

- **Phases and gates.** SKILL.md opens with a table — each phase's needs, what it produces, and which lanes may
  run at once — and a workflow of eight phases with two gates. Nothing starts before its input exists.
- **Gate 1** runs `script-reviewer` on the saved `script.md`, then posts a plan card. There is no clock: a model
  cannot time a wait and a reply cannot arrive mid-turn, so the work the plan does not govern (folder, toolkit,
  `helpers.js`, the sound plan) stands in for the wait, and the run then hands off or carries on. Unattended
  runs never wait (`references/intake.md`, "The plan card, and why it has no clock").
- **Build lanes.** From three scenes up, one agent per plate, each writing `plate_<n>_<slug>.js` (object `P<n>`)
  and proving it with its own probe and range sheet in `qa/plate_<n>/`. Assembly concatenates `helpers.js` and
  then the plates in film order — order is load-bearing, because a plate's `enter` evaluates when its `const`
  does. Seam-anchor constants live in `helpers.js`. Contract and failure handling: `references/build-lanes.md`.
- **One shared QA render** at the end of assembly; the reviewers reuse it. Gate 2's fix loop re-runs only the
  checks a change affects, and stops after three rounds.
- **Commands** `/doodle-plan` (0 to Gate 1) and `/doodle-build` (3 to 5), alongside `/doodle-qa` and
  `/doodle-render`. All four are the user's to type; a model follows the same phases by hand.
- **Agents** each start with a `## Preconditions` section that stops when their input is missing, and their
  descriptions say which command invokes them and that they never start on their own.
- **Toolkit:** `render.mjs` reports a story that throws while loading within about 15 s, naming the identifier,
  instead of waiting out a 90 s timeout; a harmless error before fonts load no longer kills a render; and
  `--sheet`, `--strips` and `--seams` clear their own stale output, since `qa/` now outlives a run.

## How it was checked

- Two independent reviews. The first found three blockers (the unimplementable timer, cross-plate anchors that
  broke a lane's probe, and a lane `speed_check` that measured nothing) and showed three acceptance checks could
  be satisfied by prose meaning the opposite. The second found the fixes' own errors (a wrong `readTime` formula,
  a folder created with a command that cannot create one, a renderer change that could kill a healthy render) and
  defeated all nine W checks at once. Every finding was fixed; its defeat harness now fails on all nine.
- A dry run built a three-scene, 32.8 s film ("Paper Flight") through the new commands, with three build lanes
  drawing their plates in parallel. The assembled film built and rendered first time: `text_check` CLEAN,
  `speed_check` ok on both seams. Its lanes surfaced the header, `callout`, script-cell and beat-window facts now
  in the references.
- `acceptance_check.py`: 91 static checks, and the `--full` tier (builds, probes, renders, timing, smoke test on
  every bundled film). CI now runs the static tier, and watches the checker, `ACCEPTANCE.md` and the marketplace
  entry as well as the plugin.

## Known limits

- **The W checks read prose.** They catch rules that decay by accident; they are not proof against text written
  to satisfy the words and mean the opposite. `ACCEPTANCE.md` says so. The gate for these documents is review.
- `speed_check.mjs` still exits 0 with no seam lines on a one-plate probe. The documents no longer ask a lane to
  run it; the tool itself does not warn.
- A story that swallows its own load error (a `try` around `defineStory`) still waits out the 90 s timeout.
- The fan-out threshold ("three scenes up", "about 30 seconds or less") gives opposite answers for a three-scene
  28-second film. The three documents agree on the wording; the wording is ambiguous at that edge.
- Gate 1's review took about ten minutes on the dry run's three-scene film.
